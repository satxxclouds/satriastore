01 — Pengantar

Apa itu Pemrograman?

Pemrograman adalah proses memberi instruksi kepada komputer untuk melakukan tugas tertentu. Komputer tidak bisa memahami bahasa manusia secara langsung, jadi kita menulis kode menggunakan bahasa pemrograman yang kemudian diterjemahkan menjadi perintah mesin.

Setiap program pada dasarnya adalah kumpulan dari instruksi berurutan yang membentuk logika. Semakin kompleks logika yang ingin dijalankan, semakin penting memahami konsep dasar terlebih dahulu.

Intinya: kamu menulis kode → komputer menerjemahkan → komputer menjalankan hasilnya. Semua bahasa pemrograman hanyalah alat untuk menyusun logika dengan cara yang bisa dibaca manusia maupun mesin.
  • Algoritma — urutan langkah logis untuk menyelesaikan masalah
  • Bahasa Pemrograman — alat untuk menulis algoritma dalam bentuk kode
  • Kompiler / Interpreter — penerjemah kode menjadi bahasa mesin
hello.js 
// Program pertama: Hello World
function sapa(nama) {
    return `Halo, ${nama}!`;
}

const pesan = sapa("Dunia");
console.log(pesan);

// Output: Halo, Dunia!
02 — Variabel & Tipe Data

Menyimpan Nilai dalam Memori

Variabel adalah wadah untuk menyimpan nilai di memori komputer. Setiap variabel memiliki nama dan tipe data yang menentukan jenis nilai apa yang bisa disimpan di dalamnya.

Memahami tipe data sangat penting karena setiap tipe memiliki perilaku, operasi, dan kegunaan yang berbeda. Salah memilih tipe data bisa menyebabkan error atau hasil yang tidak diharapkan.

int
Bilangan bulat
float
Bilangan desimal
string
Teks
boolean
True / False
array
Kumpulan nilai
object
Struktur kompleks
variabel.js 
// Mendeklarasikan variabel
let umur = 25;              // number
const nama = "Andi";       // string
let aktif = true;          // boolean
let hobi = ["baca", "koding"]; // array

// Menggabungkan nilai
console.log(`${nama} berumur ${umur} tahun`);

// Output: Andi berumur 25 tahun
03 — Operator

Simbol yang Melakukan Aksi

Operator adalah simbol yang digunakan untuk melakukan operasi pada nilai. Ada beberapa kategori operator dasar yang selalu ada di setiap bahasa pemrograman.

+
Aritmatika
Operasi matematika dasar: penjumlahan, pengurangan, perkalian, pembagian, dan modulus (sisa bagi).
=
Perbandingan
Membandingkan dua nilai dan menghasilkan boolean: sama dengan, lebih besar, lebih kecil, dan sebagainya.
&&
Logika
Menggabungkan kondisi: AND, OR, dan NOT. Sangat penting untuk membentuk logika percabangan yang kompleks.
+=
Penugasan
Memberi nilai ke variabel. Bentuk gabungan seperti += mempersingkat operasi umum.
04 — Kontrol Alur

Mengatur Arah Program

Secara default, program berjalan dari atas ke bawah. Kontrol alur memungkinkan kita mengubah urutan eksekusi berdasarkan kondisi atau mengulang blok kode tertentu.

Ada dua bentuk utama kontrol alur: percabangan (if/else, switch) dan perulangan (for, while). Keduanya adalah alat wajib untuk membangun logika program apa pun.

  • if / else — jalankan blok jika kondisi terpenuhi
  • switch — pilih satu dari banyak kemungkinan
  • for — ulangi dengan jumlah yang diketahui
  • while / do-while — ulangi selama kondisi terpenuhi
kontrol.js 
// Percabangan
if (nilai >= 75) {
    console.log("Lulus");
} else if (nilai >= 60) {
    console.log("Perbaikan");
} else {
    console.log("Gagal");
}

// Perulangan
for (let i = 1; i <= 3; i++) {
    console.log(`Putaran ke-${i}`);
}
05 — Fungsi

Blok Kode yang Bisa Digunakan Ulang

Fungsi adalah sekumpulan instruksi yang diberi nama, sehingga bisa dipanggil berkali-kali tanpa menulis ulang kode yang sama. Ini adalah konsep inti dari DRY — Don't Repeat Yourself.

Fungsi dapat menerima parameter (input) dan mengembalikan nilai (output). Sebuah fungsi yang baik melakukan satu tugas dengan jelas, sehingga mudah diuji dan dirawat.

Tips: jika sebuah blok kode kamu tulis lebih dari dua kali, sebaiknya jadikan fungsi. Ini membuat kode lebih pendek, lebih mudah dibaca, dan lebih mudah diperbaiki.
fungsi.js 
// Deklarasi fungsi
function hitungLuas(panjang, lebar) {
    return panjang * lebar;
}

// Arrow function (lebih singkat)
const hitungLuas2 = (p, l) => p * l;

// Memanggil fungsi
const luas = hitungLuas(5, 3);
console.log(luas); // 15
06 — Struktur Data

Cara Mengorganisir Banyak Data

Struktur data menentukan bagaimana data disimpan dan diakses. Memilih struktur yang tepat bisa membuat program lebih cepat dan lebih mudah dipahami.

A
Array / List
Kumpulan nilai yang berurutan dan dapat diakses dengan indeks. Cocok untuk data yang jumlahnya banyak dan sejenis, seperti daftar nama atau angka.
B
Object / Dictionary
Kumpulan pasangan kunci-nilai. Cocok untuk merepresentasikan entitas yang memiliki banyak atribut, seperti data pengguna atau produk.
C
Stack & Queue
Struktur data khusus dengan aturan akses: Stack (LIFO — terakhir masuk, pertama keluar) dan Queue (FIFO — pertama masuk, pertama keluar).
D
Map / Set
Untuk pencarian cepat dan penyimpanan nilai unik. Set menyimpan nilai tanpa duplikat, Map menyimpan pasangan kunci-nilai dengan akses cepat.
07 — Pemrograman Berorientasi Objek

Membuat Kode Mirip Dunia Nyata

OOP (Object-Oriented Programming) adalah paradigma yang mengorganisir kode menjadi objek-objek yang merepresentasikan entitas nyata. Setiap objek memiliki atribut (data) dan metode (perilaku).

Dengan OOP, program yang kompleks bisa dipecah menjadi bagian-bagian kecil yang mandiri, sehingga lebih mudah dikembangkan dan dipelihara dalam jangka panjang.

  • Class — blueprint atau cetak biru dari objek
  • Object — instance nyata hasil dari class
  • Encapsulation — menyembunyikan detail internal
  • Inheritance — mewarisi sifat dari class lain
  • Polymorphism — satu interface, banyak bentuk
oop.js 
class Mahasiswa {
    constructor(nama, nim) {
        this.nama = nama;
        this.nim = nim;
    }

    perkenalan() {
        return `Hai, saya ${this.nama}`;
    }
}

const mhs = new Mahasiswa("Budi", "A11");
console.log(mhs.perkenalan());
// Output: Hai, saya Budi
08 — Penanganan Error

Menghadapi Kesalahan dengan Elegan

Error adalah bagian tak terpisahkan dari pemrograman. Alih-alih membiarkan program berhenti mendadak, kita bisa menangkap error dan memberikan respons yang tepat kepada pengguna.

Blok try / catch adalah pola standar di hampir semua bahasa modern untuk menangani kemungkinan kesalahan.

Prinsip: jangan pernah mengabaikan error. Tangkap, catat, dan berikan pesan yang jelas kepada pengguna — bukan pesan teknis yang membingungkan.
error.js 
try {
    const hasil = bagi(10, 0);
    console.log(hasil);
} catch (err) {
    console.error("Terjadi error:", err.message);
} finally {
    // Selalu dijalankan
    console.log("Selesai");
}

10 — Paradigma

Cara Berpikir dalam Menulis Kode

Paradigma adalah gaya atau pendekatan dalam menyusun program. Masing-masing punya kelebihan tergantung jenis masalah yang dihadapi.

Imperatif
  • Fokus pada bagaimana langkah-langkahnya
  • Kode berisi urutan perintah eksplisit
  • Contoh: C, Pascal, Assembly
  • Mudah dipahami untuk masalah sederhana
Deklaratif
  • Fokus pada apa hasil yang diinginkan
  • Kode lebih ringkas dan ekspresif
  • Contoh: SQL, HTML, Haskell
  • Kuat untuk transformasi data

Belajar Pemrograman adalah Maraton

Konsep dasar yang sudah kamu pelajari di sini adalah fondasi yang berlaku selamanya, apapun bahasa atau framework yang kamu pilih nanti. Kuasai dasarnya, dan sisanya akan terasa jauh lebih mudah.
