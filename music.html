Persiapan

Yang kamu butuhkan

Hanya tiga hal. Tidak perlu laptop mahal, tidak perlu akun, tidak perlu bayar apa pun.

01

Laptop / PC

Windows, macOS, atau Linux. Spesifikasi standar sudah lebih dari cukup.

02

VS Code

Editor kode gratis dari Microsoft. Ini akan jadi "dapur" tempat kamu menulis kode.

03

Browser

Chrome, Edge, atau Firefox. Dipakai untuk melihat hasil kode yang kamu tulis.

⏱ Estimasi waktu

Sekitar 15–20 menit untuk menyelesaikan seluruh panduan ini. Santai saja, tidak perlu buru-buru.

01

Install VS Code

Visual Studio Code (disingkat VS Code) adalah aplikasi gratis untuk menulis kode. Ini yang akan kamu pakai sepanjang belajar.

  • Buka situs resminya Ketik code.visualstudio.com di browser.
  • Klik tombol Download Tombol besar di halaman depan. Situs otomatis mendeteksi sistem operasimu.
  • Jalankan file installer Buka file yang terunduh, lalu klik Next terus sampai Install.
  • Buka VS Code Cari "Visual Studio Code" di menu Start / Spotlight / Applications.
💡 Tips saat install

Di Windows, centang opsi "Add to PATH" dan "Open with Code" saat muncul. Ini memudahkanmu membuka folder langsung dari klik kanan.

02

Buat Folder & File Pertama

Kode harus disimpan di dalam sebuah folder. Anggap saja folder ini sebagai "proyek" pertamamu.

  • Buat folder baru Di Desktop, klik kanan → New Folder → beri nama latihan-coding. Hindari spasi di nama folder.
  • Buka folder di VS Code Di VS Code: File → Open Folder → pilih folder latihan-coding.
  • Buat file baru Klik ikon "New File" di panel kiri, beri nama persis: index.html
⚠️ Penting soal nama file

Nama harus index.html — huruf kecil semua, dan berakhiran .html. Kalau salah nama, browser tidak akan mengenalinya sebagai halaman web.

03

Tulis "Hello World" Pertamamu

Sekarang bagian yang paling seru. Ketik (atau salin) kode berikut ke dalam file index.html yang tadi kamu buat.

index.html 
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Latihan Pertama</title>
</head>
<body>

  <h1>Hello World!</h1>

</body>
</html>

Setiap baris punya tugasnya sendiri:

<!>

<!DOCTYPE html>

Memberi tahu browser: "ini adalah halaman HTML versi terbaru".

<h>

<head> ... </head>

Informasi halaman yang tidak tampil di layar, seperti judul tab browser.

<b>

<body> ... </body>

Isi halaman yang benar-benar dilihat pengunjung.

h1

<h1>Hello World!</h1>

Judul paling besar. Inilah teks yang akan muncul di layar.

💡 Simpan file

Tekan Ctrl + S (Windows) atau Cmd + S (Mac). Titik putih di tab file akan hilang, tanda bahwa file sudah tersimpan.

04

Jalankan di Browser

Kode sudah ditulis. Sekarang saatnya melihat hasilnya. Ada dua cara:

Cara A — Cara cepat (tanpa ekstensi)

  • Buka folder proyekmu Buka File Explorer / Finder, cari folder latihan-coding.
  • Klik dua kali file index.html File akan terbuka otomatis di browser default kamu.

Cara B — Pakai Live Server (direkomendasikan)

Live Server membuat halaman otomatis refresh setiap kali kamu menyimpan kode. Sangat menghemat waktu.

  • Buka panel Extensions Klik ikon kotak-kotak di sidebar kiri VS Code, atau tekan Ctrl + Shift + X.
  • Cari "Live Server" Pilih yang dibuat oleh Ritwick Dey, lalu klik Install.
  • Klik "Go Live" Tombolnya ada di kanan bawah status bar VS Code. Browser akan terbuka otomatis.
🎉 Kalau berhasil

Kamu akan melihat tulisan besar Hello World! di browser. Selamat — kamu baru saja menulis kode pertamamu!

05

Beri Warna dengan CSS

HTML mengatur isi halaman. CSS mengatur tampilannya — warna, ukuran, posisi. Tambahkan blok <style> di dalam <head>:

index.html — di dalam <head> 
<style>
  body {
    margin: 0;
    height: 100vh;
    display: flex;
    justify-content: center;
    align-items: center;
    background: #f4f4f5;
    font-family: Arial, sans-serif;
  }

  h1 {
    color: #0a0a0a;
    font-size: 48px;
  }
</style>
🎨

background & color

Mengatur warna latar dan warna teks. Format #0a0a0a disebut kode hex.

📐

display: flex

Teknik untuk menengahkan elemen, baik secara horizontal maupun vertikal.

06

Bikin Interaktif dengan JavaScript

JavaScript membuat halamanmu bisa merespons tindakan pengguna. Tambahkan kode ini tepat sebelum </body>:

index.html — sebelum </body> 
<script>
  const judul = document.querySelector('h1');

  judul.addEventListener('click', function () {
    judul.textContent = 'Kamu berhasil! 🎉';
    judul.style.color = '#3a3a3f';
  });
</script>

Simpan file, lalu klik tulisan Hello World! di browser. Teksnya akan berubah dan warnanya berganti. Itulah JavaScript bekerja.

🔍 Cara membaca kodenya

document.querySelector('h1') mencari elemen h1. addEventListener('click', ...) artinya "saat diklik, jalankan perintah ini".

<html lang="id">

  <meta charset="UTF-8">

  <style>

      font-size: 48px;
      cursor: pointer;
      transition: color .3s ease;
    }

<body>

  <h1>Hello World!</h1>

  <script>
    const judul = document.querySelector('h1');

    judul.addEventListener('click', function () {
      judul.textContent = 'Kamu berhasil! 🎉';
      judul.style.color = '#3a3a3f';
    });
  </script>

</body>
</html>
Latihan Tambahan

Coba sendiri, centang satu per satu

Klik setiap item untuk menandainya selesai. Mulai dari yang paling mudah.

  • Ganti teks Hello World! menjadi namamu sendiri.
  • Ubah warna #0a0a0a menjadi warna favoritmu.
  • Tambahkan paragraf baru dengan <p>Ini paragraf keduaku</p>.
  • Tambahkan gambar dengan <img src="foto.jpg" width="200">.
  • Buat tombol dengan <button>Klik Aku</button>.
  • Buat tombol itu menampilkan alert saat diklik dengan JavaScript.
  • Pisahkan CSS ke file style.css dan hubungkan dengan <link>.
  • Buat halaman kedua bernama tentang.html dan tautkan dengan <a href>.
Troubleshooting

Kalau ada yang tidak jalan

Tenang, semua pemula pernah mengalami ini. Ini solusi paling umum:

Halaman kosong / putih

Cek apakah semua tag sudah ditutup. <body> harus punya pasangan </body>. Pastikan juga file sudah disimpan dengan Ctrl + S.

Kode muncul sebagai teks di browser

Berarti file-nya bukan .html. Cek lagi nama file — mungkin tersimpan sebagai index.html.txt. Aktifkan "tampilkan ekstensi file" di File Explorer.

Perubahan tidak muncul

Simpan file dulu, lalu refresh browser dengan Ctrl + F5 (hard refresh). Kalau pakai Live Server, perubahan akan muncul otomatis.

Warna / gaya tidak berubah

Pastikan blok <style> berada di dalam <head>, bukan di luar, dan tidak ada salah ketik pada tanda { }.

JavaScript tidak bereaksi

Buka Console browser dengan F12 → tab Console. Pesan merah di sana biasanya menunjukkan baris yang bermasalah.
